# 强脑手套（右手）引脚表

权威来源：`小华项目/强脑手套/O02.eprj2` 中主采集板的原理图网络。

## 串口与调试

| 网络 | HC32F460 引脚 |
| --- | --- |
| `USART1_TX` | `PA11` |
| `USART1_RX` | `PA12` |
| `SWDIO` | `PA13` |
| `SWCLK` | `PA14` |
| `MD` | `PB11` |

## 五指模拟输入与复用器使能

| 部位 | ADC 网络 / 引脚 | 低有效 EN / 引脚 |
| --- | --- | --- |
| 拇指 | `THUMB-RP_AD0` / `PA1 (ADC1_IN1)` | `THUMB-EN0` / `PA6` |
| 食指 | `INDEX-RP_AD0` / `PA2 (ADC1_IN2)` | `INDEX-EN0` / `PA7` |
| 中指 | `MIDDLE-RP_AD0` / `PA3 (ADC1_IN3)` | `MIDDLE-EN0` / `PB0` |
| 无名指 | `RING-RP_AD0` / `PA4 (ADC12_IN4)` | `RING-EN0` / `PB1` |
| 小指 | `PINKY-RP-AD0` / `PA5 (ADC12_IN5)` | `PINKY-EN0` / `PB2` |

五个复用器共用地址：

| 网络 | 引脚 |
| --- | --- |
| `AS_S0` | `PH2` |
| `AS_S1` | `PC13` |
| `AS_S2` | `PC14` |

## 其他

| 网络 | 引脚 |
| --- | --- |
| `NTC` | `PA0 (ADC1_IN0)` |

当前工程构建右手。左右手的 MCU 引脚、食指 J2 接口针脚网络和扫描时序相同；有效点掩码的差别只在食指。右手特有 `(X4,Y2)`，左手特有 `(X3,Y2)`、`(X3,Y3)`。完整对照见 `../LEFT_RIGHT_DIFFERENCES.md`。

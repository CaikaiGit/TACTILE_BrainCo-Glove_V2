# 强脑手套 V2.0 引脚表

权威来源：`V2.0/导出/Netlist_O02-YS-CJB-02_2026-09-09.tel` 与
`SCH_O02-YS-CJB-02_2026-09-09.pdf`。左右手 PCB 物理镜像，但 MCU 逻辑网络、
扫描顺序和上报顺序一致。

## 串口与调试

| 网络 | HC32F460PEHB 引脚 |
| --- | --- |
| `USART1_TX` | `PA12` |
| `USART1_RX` | `PA11` |
| `SWDIO` | `PA13` |
| `SWCLK` | `PA14` |
| `MD` | `PB11` |

## ADC、复用器地址与使能

五个手指复用器的公共模拟输出为单路 `AD0`，连接 `PA0 (ADC1_CH0)`。
扫描时仅使能当前手指的复用器，EN 为低有效。

| 网络 | HC32F460PEHB 引脚 | 用途 |
| --- | --- | --- |
| `AD0` | `PA0` | 公共 ADC 输入 |
| `AS_S0` | `PE1` | 五个复用器共用地址位 0 |
| `AS_S1` | `PD6` | 五个复用器共用地址位 1 |
| `AS_S2` | `PD9` | 五个复用器共用地址位 2 |
| `EN0` | `PD8` | 拇指复用器使能 |
| `EN1` | `PC11` | 食指复用器使能 |
| `EN2` | `PC4` | 中指复用器使能 |
| `EN3` | `PA5` | 无名指复用器使能 |
| `EN4` | `PC3` | 小指复用器使能 |

## 手指 Y 驱动线

V2 各手指使用独立 Y 线；拇指、食指、中指、无名指为 Y0–Y10，小指为 Y0–Y8。

| Y | 拇指 | 食指 | 中指 | 无名指 | 小指 |
| --- | --- | --- | --- | --- | --- |
| Y0 | PA10 | PE8 | PA1 | PE4 | PC12 |
| Y1 | PD11 | PB10 | PB2 | PC0 | PB8 |
| Y2 | PA9 | PE9 | PA2 | PB9 | PA15 |
| Y3 | PD10 | PE14 | PE7 | PC1 | PD7 |
| Y4 | PC9 | PE10 | PA4 | PC13 | PD1 |
| Y5 | PD12 | PE15 | PB1 | PB5 | PD4 |
| Y6 | PC6 | PE11 | PA3 | PE5 | PB3 |
| Y7 | PD13 | PB12 | PC5 | PH2 | PB4 |
| Y8 | PC7 | PE12 | PA7 | PC14 | PD3 |
| Y9 | PD14 | PB13 | PB0 | PC15 | - |
| Y10 | PC8 | PE13 | PA6 | PE6 | - |

当前 Keil 工程只保留一套源码。手型由 Target 的 `HAND_RIGHT` 宏选择；未定义时为左手。

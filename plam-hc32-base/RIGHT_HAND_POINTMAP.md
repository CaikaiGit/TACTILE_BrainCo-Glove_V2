# 强脑手套右手点位与上传协议

## 点位判定方法

有效点由 `O02.eprj2` 中手指 PCB 的焊盘网络交叉确定：每个传感点必须同时存在一个 `Xn` 电极焊盘和对应的 `Yn` 电极焊盘。图片轮廓只用于观察传感区之间的物理间隙，不用于判断点位是否有效。

坐标定义为 **X=列、Y=行**。硬件按 **手指→Y→有效X** 采样：每次只切换一次 PGA 手指输入，再按 Y 递增、有效 X 递增读取。无效交叉点不采集，也不上传。

下表每格列出该 Y 行存在的 X；未列出的交叉点在采样和上传时均置 0。

| 手指 | Y 范围与有效 X | 总有效点 |
| --- | --- | ---: |
| 拇指 | Y0–Y1: X2,X3；Y2: X3；Y3: X3,X7；Y4: X0,X3,X6,X7；Y5–Y6: X0–X7；Y7–Y12: X1–X6 | 63 |
| 食指（右） | Y0–Y1: X3,X4；Y2: X4；Y3: X7；Y4: X0,X3,X6,X7；Y5–Y6: X0–X7；Y7–Y12: X2–X7 | 62 |
| 中指 | Y0–Y1: X2,X3；Y2: X3；Y3: X3,X7；Y4: X0,X3,X6,X7；Y5–Y6: X0–X7；Y7–Y15: X2–X7 | 81 |
| 无名指 | 与中指相同 | 81 |
| 小指 | Y0–Y1: X2,X3；Y2: X3；Y3: X3,X7；Y4: X0,X3,X6,X7；Y5–Y6: X0–X7；Y7–Y12: X2–X7 | 63 |

拇指表格采用采集板/MCU的 Y 编号。采集板 Y0～Y12 对应拇指软板标注的 Y1～Y13，软板名称整体大1。

## 与左手的差异

左右手的 MCU 引脚、连接器逻辑网络和扫描顺序相同。物理镜像不需要在程序中反转 X 或 Y。

只有食指 Y2 的有效点不同：右手为 X4，左手为 X3。两手的 `(X3,Y3)` 均去除，Y3 都只保留 X7，因此两手食指均为62点、整手均为350点。其余四指点位相同。完整对照见 `../LEFT_RIGHT_DIFFERENCES.md`。

## 当前区域划分

区域编号与小米手套一致：`1=指尖`、`2=指中`、`3=指根`。

| 手指 | 指尖 | 指中 | 指根 |
| --- | --- | --- | --- |
| 拇指 | Y0–Y6 | Y7–Y12 | 无 |
| 食指 | Y0–Y6 | Y7–Y9 | Y10–Y12 |
| 中指 | Y0–Y6 | Y7–Y10 | Y11–Y15 |
| 无名指 | Y0–Y6 | Y7–Y10 | Y11–Y15 |
| 小指 | Y0–Y6 | Y7–Y9 | Y10–Y12 |

拇指在 PCB 上只有两个明显分离的点阵，因此上传区域 1 和区域 2，不使用区域 3。

## 串口上传

外层沿用小米手套：

```text
3C 3C | channel=02 | flags=00 | payload_len(LE) | payload | CRC16(LE) | 3E 3E
```

每只手指单独一包，payload：

```text
byte 0: (part_id << 4) | region_count
repeat region_count:
    region_id | valid_count | packed_rows=1 | valid_data[]
```

每个采样点占 2 字节，按小端序上传：`ADC低字节, ADC高字节`。保留 ADC 原始精度，不再右移 4 位压缩。USART1 波特率为 2 Mbps。

`part_id`：拇指 1、食指 2、中指 3、无名指 4、小指 5。每个区域只上传有效点，顺序是固定点位表中的 Y 递增、X 递增，不增加逐点坐标或位图；接收端按同一份固定点位表还原坐标。右手各指点数为 `63+62+81+81+63=350`，五包连同外层协议共797字节。
